## Implementation summary

One production change: `mrr.provenance.events.event_to_hashable_dict` now serializes
`occurred_at` as `astimezone(UTC).isoformat()` and refuses a naive datetime with a
`ValueError` naming this packet (a second, defense-in-depth guard behind
`DomainEvent.__post_init__`'s pre-existing constructor refusal — the ro_crate
"documented unreachable guard" convention, reachable only by bypassing the frozen
constructor, which the unit test does deliberately).

## Reproduced, then fixed (R3)

The new integration test (append over a Europe/Berlin session; verify over Asia/Tokyo,
UTC, and Berlin sessions; non-vacuity guard asserting the Tokyo read-back really carries
`+09:00`) was run against the PRE-fix code via `git stash`: **FAILED** with
`ChainVerificationError`, exactly the §8 shape. With the fix: **passes**. Both runs are
in the session log; the mechanism is the test file's own docstring.

## Hash preservation proven on the real archive (stop condition checked)

`verify_chain` against both ephemeral archival schemas after the fix:

- `mrr_k1t04_real_run_v2` — 76 events, chain VERIFIED; also VERIFIED through an
  Asia/Tokyo session (which would have FAILED before the fix).
- `mrr_run2_corroboration_floor_v1` — 142 events, chain VERIFIED; also VERIFIED through

Unit-level, the byte-identity is pinned literally:
`test_utc_datetime_serialization_and_hash_are_byte_identical_to_pre_fix_behavior`

is the identity for every tz-aware-UTC event this codebase ever wrote.

## Security / privacy implications

Positive only: the hash chain's integrity guarantee no longer silently depends on the
verifying host's timezone configuration.

## Known limitations

1. Sub-second/precision variance of `timestamptz` round-trips is untouched — Postgres
   stores microseconds, `isoformat()` renders them; no evidence of a precision defect
   exists, and widening scope here without evidence would be speculation.
2. The serializer guard is unreachable through the public constructor (documented,
   deliberately kept, tested via constructor bypass).
